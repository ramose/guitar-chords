# Guitar Chord Chart

Interactive guitar chord chart — pick a base note, then a chord shape, and see the fingering.

- **12 roots** (C–B, with a ♯/♭ toggle)
- **22 shapes** grouped as Triads, Sevenths, Extended (9, maj9, m9, add9, 11, 13…) and Suspended — 264 chords in total
- Each chord shows a fingered diagram (open position when one exists, otherwise the lowest barre), its notes with intervals, formula, difficulty, and playing instructions
- Full 12-fret neck map of every chord tone, plus two alternative voicings (E-shape and A-shape) you can promote to the main diagram
- Strum and pick-one-by-one playback (Web Audio, no samples), and Surprise me for a random chord

Open `index.html` in a browser — no build step, no server needed. Works offline except for the Google Fonts it loads for the typeface.
